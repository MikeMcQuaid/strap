👢 Strap

Strap is a script to bootstrap a minimal macOS development system. This does not assume you're doing Ruby/Rails/web development but installs the minimal set of software every macOS developer will want.

To Strap your system:

  1. Download the strap.sh script (or view it in your browser first).
  2. Run it in Terminal.app with bash ~/Downloads/strap.sh.
  3. After installing Homebrew, Strap offers to log in to GitHub using the GitHub CLI. This sets up Git and fetches your dotfiles and Brewfile. You can decline the prompt, or skip GitHub setup with bash ~/Downloads/strap.sh --no-github.
  4. If something failed, run bash ~/Downloads/strap.sh --debug for more debugging output.
  5. Install additional software with brew install.

Configure your Mac

Pass options to the downloaded script or set environment variables in your terminal. For example, to skip email lookup and configuration: 

bash ~/Downloads/strap.sh --no-git-email

The equivalent environment variable is:

STRAP_NO_GIT_EMAIL=1 bash ~/Downloads/strap.sh
OptionEnvironment variableBehaviour
--no-githubSTRAP_NO_GITHUB=1 Skip GitHub login and profile lookup, including an existing login. Supplied values still apply.
--git-name NAMESTRAP_GIT_NAME Set Git's name and the name in the login-screen recovery message.
--no-git-nameSTRAP_NO_GIT_NAME=1 Skip name lookup and configuration.
--git-email EMAILSTRAP_GIT_EMAIL Set Git's email and the email in the login-screen recovery message.
--no-git-emailSTRAP_NO_GIT_EMAIL=1 Skip email lookup and configuration.
--github-user USERSTRAP_GITHUB_USER Set Git's GitHub username and select the owner of dotfiles and Brewfile repositories.
--no-github-userSTRAP_NO_GITHUB_USER=1 Skip GitHub username lookup and configuration, and fetching dotfiles and Brewfile repositories.
--debugSTRAP_DEBUG=1 Show debugging output.
--helpNone Show help without changing your Mac.

To supply your details and skip GitHub login:

bash ~/Downloads/strap.sh --no-github \
  --git-name "Your Name" \
  --git-email "you@example.com" \
  --github-user "username"

You can also supply all of these through environment variables:

STRAP_NO_GITHUB=1 \
STRAP_GIT_NAME="Your Name" \
STRAP_GIT_EMAIL="you@example.com" \
STRAP_GITHUB_USER="username" \
bash ~/Downloads/strap.sh

Flags override environment variables; the last flag for a field wins. A STRAP_NO_*=1 variable overrides the corresponding environment value. Empty environment values are ignored; use a --no-* flag to skip a field. Skipping leaves existing Git settings and any existing login-screen message untouched. Existing Git name and email are otherwise preserved unless you supply replacements; missing values are fetched from GitHub. The login-screen recovery message is only updated when both name and email are available.

GitHub authentication

Strap reuses your active GitHub CLI login or offers to log in after installing Homebrew. GitHub CLI is installed if needed when you accept or supply a token. You can decline; installation continues without automatic profile lookup if you decline or login fails. Credentials stay on your Mac and are never embedded in the downloaded script.

When email lookup is needed, login requests user:email permission to read your primary verified email, even if it is private. If an existing login lacks this permission, supply --git-email, skip with --no-git-email or run gh auth refresh --hostname github.com --scopes user:email before retrying. Private repositories must be accessible to your active account, including any organisation authorisation required for GitHub CLI.

Unattended runs never prompt for GitHub login. They can reuse an existing login or use GH_TOKEN (preferred) or GITHUB_TOKEN from the environment. Repositories that Git cannot access are skipped without terminal credential prompts. Skipping a GitHub username still allows your local ~/.Brewfile and an existing ~/.dotfiles/script/strap-after-setup to run.

Additional environment variables

STRAP_ISSUES_URL
An optional support URL printed when installation fails.
CUSTOM_HOMEBREW_TAP
An optional tap to install with brew tap. Separate multiple arguments with spaces.
CUSTOM_BREW_COMMAND
An optional command to run with brew after the other installation stages.
STRAP_NO_SOFTWAREUPDATE=1
Skip installing remaining software updates. The update check still runs.
STRAP_CI=1
For disposable CI machines: skip GitHub setup and remaining software-update installation.
