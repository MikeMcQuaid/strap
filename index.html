Strap is a script to bootstrap a minimal macOS development system. This does not assume you're doing Ruby/Rails/web development but installs the minimal set of software every macOS developer will want.

To Strap your system:

  1. Download the strap.sh script (or view it in your browser first).
  2. Run it in Terminal.app with bash ~/Downloads/strap.sh.
  3. After installing Homebrew, follow the GitHub CLI login prompt to configure Git and fetch your dotfiles and Brewfile. Strap reuses an existing login.
  4. If something failed, run bash ~/Downloads/strap.sh --debug for more debugging output.
  5. Install additional software with brew install.

See the README for local configuration environment variables and flags.
