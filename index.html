Strap is a script to bootstrap a minimal macOS development system. This does not assume you're doing Ruby/Rails/web development but installs the minimal set of software every macOS developer will want.

To Strap your system:

  1. Download the strap.sh script (or view it in your browser first).
  2. Run it in Terminal.app with bash ~/Downloads/strap.sh.
  3. After installing Homebrew, Strap offers to log in to GitHub using the GitHub CLI. This sets up Git and fetches your dotfiles and Brewfile. You can decline the prompt, or run without prompts with bash ~/Downloads/strap.sh --non-interactive.
  4. If something failed, run bash ~/Downloads/strap.sh --debug for more debugging output.
  5. Install additional software with brew install.

Configure your Mac

Set environment variables in your terminal to supply your Git identity and the owner of your dotfiles and Brewfile repositories: 

STRAP_GIT_NAME="Your Name" \
STRAP_GIT_EMAIL="you@example.com" \
STRAP_GITHUB_USER="username" \
bash ~/Downloads/strap.sh

Existing Git name and email are preserved unless you supply replacements; missing values are fetched from GitHub when authenticated. Empty environment values are ignored. The login-screen recovery message is only updated when both name and email are available and the message has changed.

Use --non-interactive or STRAP_NONINTERACTIVE=1 to run without prompts, --debug for debugging output or --help for usage. Non-interactive mode is automatic when standard input is not a TTY or CI=1. Non-interactive runs can reuse an existing GitHub login but never start a new login. Privileged operations require sudo access without a password prompt, such as a previously authenticated sudo session.

GitHub authentication

Strap reuses your active GitHub CLI login or offers to log in after installing Homebrew. GitHub CLI is installed if needed when you accept or supply a token. You can decline; installation continues without automatic profile lookup if you decline or login fails. Credentials stay on your Mac and are never embedded in the downloaded script.

When email lookup is needed, login requests user:email permission to read your primary verified email, even if it is private. If an existing login lacks this permission, set STRAP_GIT_EMAIL or run gh auth refresh --hostname github.com --scopes user:email before retrying. Private repositories must be accessible to your active account, including any organisation authorisation required for GitHub CLI.

Unattended runs never prompt for GitHub login. They can reuse an existing login or use GH_TOKEN (preferred) or GITHUB_TOKEN from the environment. Repositories that Git cannot access are skipped without terminal credential prompts. Without a GitHub username, your local ~/.Brewfile and an existing ~/.dotfiles/script/strap-after-setup still run.
